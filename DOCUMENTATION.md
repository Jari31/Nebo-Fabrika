# Obsidian

The Obsidian .mds within the [Obsidian folder](Undecided_Game_Proj/Obsidian%20Files) explain every algorithm currently implemented. Alongside that, they show diagrams to visualize the flow. (W.I.P. and might be outdated in some parts.)

### Color-coding for nodes within Obsidian:

| Color    | Def                      |
| -------- | ------------------------ |
| _Red_    | Unfinished and WIP code  |
| _Green_  | Finished code            |
| _Yellow_ | Bugged code              |
| _Blue_   | Pure documentation notes |

### Recommended Obsidian Extensions

- DataviewJS $-$ Allows for WebGL and WebGPU use within Obsidian itself.
- Execute Code $-$ Allows for the execution of quite a lot of languages right within Obisidian itself (e.g., C++, JavaScript, Python etc.)
- Juggl $-$ Allows for the use of CSS for more formatted and cleaner documentation.
- Reminder $-$ Allows for check-marks next to text, which makes tracking to-dos easier.
